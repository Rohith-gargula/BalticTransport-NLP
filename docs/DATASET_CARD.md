# Dataset Card: BalticTransport-NLP
## Dataset summary
A planned multilingual corpus of transport/logistics texts in Latvian (lv), Russian (ru), and English (en), labeled by topic.

## Status
Starter repository currently includes only 12 synthetic smoke-test examples for software testing. They are not real articles and must not be used to claim model quality.

## Intended task
Single-label topic classification: delay, safety, tariffs, infrastructure, other.
